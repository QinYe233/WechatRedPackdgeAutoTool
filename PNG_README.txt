# PNG 模板图片文件夹

## 📁 文件说明

此文件夹包含程序所需的三个模板图片：

### 1. red_packet_icon.png - 红包图标
- **位置**：微信聊天列表中的红包图标
- **建议尺寸**：50x50 像素左右
- **截图范围**：只截取红包图标本身

### 2. open_button.png - 打开按钮
- **位置**：红包详情页中的"开"字按钮
- **建议尺寸**：80x80 像素左右
- **截图范围**：包含完整的圆形按钮

### 3. back_icon.png - 关闭按钮
- **位置**：红包详情页右上角的关闭按钮（×）
- **建议尺寸**：30x30 像素左右
- **截图范围**：只截取关闭图标本身

## 📸 截图技巧

1. **使用微信截图**：按 `Alt+A` 调出微信截图工具
2. **精确截取**：只截取按钮本身，避免包含过多背景
3. **保持清晰**：确保图片清晰，无模糊或失真
4. **PNG格式**：保存为 PNG 格式，保留透明度

## 🔄 更新图片

如果微信界面更新，导致识别失败，请：

1. 重新截取对应的按钮图片
2. 替换此文件夹中的文件
3. 保持文件名不变

## ⚠️ 注意事项

- 不同屏幕分辨率可能需要不同的模板图片
- 微信深色/浅色主题可能影响识别效果
- 图片质量直接影响识别准确率
