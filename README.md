# 🧧 微信红包自动抢夺程序

一个基于图像识别的微信红包自动抢夺工具，通过 OpenCV 模板匹配技术实现自动识别和点击。———— 仅支持桌面Wechat

## ✨ 功能特点

- 🎯 **自动识别红包**：实时扫描屏幕，发现红包立即点击
- ⚡ **快速响应**：20ms 检测间隔，抢红包快人一步
- 🛡️ **防误触机制**：关闭按钮独立配置，避免误点其他程序
- 📊 **实时统计**：显示发现/打开数量、成功率等数据
- 🔧 **灵活配置**：支持自定义匹配阈值、搜索区域等参数

## 📋 工作流程

```
1. 查找红包图标 → 点击
         ↓
2. 查找打开按钮 → 点击（0.5秒超时）
         ↓
3. 等待0.5秒 → 查找关闭按钮 → 点击
         ↓
4. 返回第1步，循环执行
```

## 🚀 快速开始

### 环境要求

- Python 3.7+
- Windows 10/11（理论支持 macOS/Linux）
- 微信桌面版

### 安装依赖

```bash
pip install opencv-python numpy pyautogui
```

### 准备模板图片

需要准备三张截图（PNG格式）：(已经打包在png文件夹)

1. **红包图标** (`red_packet_icon.png`)
   - 截取聊天列表中的红包图标
   - 建议尺寸：50x50 左右

2. **打开按钮** (`open_button.png`)
   - 截取红包详情页的"开"按钮
   - 建议尺寸：80x80 左右

3. **关闭按钮** (`back_icon.png`)
   - 截取红包详情页的关闭按钮（×）
   - 建议尺寸：30x30 左右

**截图技巧：**
- 使用微信自带截图（Alt+A）或系统截图工具
- 只截取按钮本身，避免包含过多背景
- 确保图片清晰，无模糊或失真

### 配置程序

编辑 `wechat_red_packet_auto.py`，修改配置区：


(在wechat_red_packet_auto.py文件225行处可更改```一般不需要改)

```python
config = {
    # 1. 修改图片路径
    'red_packet_path': r"C:\path\to\red_packet_icon.png",
    'open_button_path': r"C:\path\to\open_button.png",
    'back_button_path': r"C:\path\to\back_icon.png",
    
    # 2. 基础设置（可选）
    'threshold': 0.8,              # 红包/打开按钮匹配度：80%
    'interval': 0.02,              # 检测间隔：20ms
    'post_click_delay': 0.05,      # 点击后延迟：50ms
    'open_button_timeout': 0.5,    # 打开按钮超时：0.5秒
    
    # 3. 防误触配置（重要）
    'back_button_delay': 0.5,      # 等待0.5秒再查找关闭按钮
    'back_button_threshold': 1.0,  # 关闭按钮100%匹配（推荐）
    'back_button_search_region': None,  # 暂时设为None，稍后配置
}
```

## 🎯 进阶配置

### 设置关闭按钮搜索区域（强烈推荐）

为了防止误识别其他程序的关闭按钮，建议限制搜索区域：

#### 步骤 1：运行区域选择工具

```bash
python select_region.py
```

#### 步骤 2：可视化选择区域

1. 打开微信红包详情页（显示关闭按钮）
2. 按 `Enter` 启动选择工具
3. 屏幕变黑后，用鼠标拖动选择包含关闭按钮的区域
4. 松开鼠标确认选择

#### 步骤 3：复制配置参数

工具会输出类似这样的参数：

```python
'back_button_search_region': (452, 198, 327, 575),
```

复制到主程序的 `config` 字典中。

### 参数调优指南

#### 1. 匹配阈值 (threshold)

| 值 | 说明 | 适用场景 |
|---|---|---|
| 0.7 | 宽松匹配 | 图片质量不佳、有轻微变形 |
| 0.8 | 标准匹配 | 大多数情况（推荐） |
| 0.9 | 严格匹配 | 需要高精度识别 |
| 1.0 | 完全匹配 | 防止误识别（用于关闭按钮） |

#### 2. 检测间隔 (interval)

| 值 | 说明 | CPU占用 |
|---|---|---|
| 0.01 | 100次/秒 | 高 |
| 0.02 | 50次/秒 | 中等（推荐） |
| 0.05 | 20次/秒 | 低 |

#### 3. 关闭按钮配置（防误触三件套）

```python
# 推荐配置
'back_button_delay': 0.5,                        # 延迟等待
'back_button_threshold': 1.0,                    # 100%匹配
'back_button_search_region': (x, y, w, h),       # 限制区域
```

### 常见问题

#### Q1: 识别不到红包/按钮？

**解决方案：**
- 检查图片路径是否正确
- 降低 `threshold` 值（如改为 0.7）
- 重新截取更清晰的模板图片
- 确保微信窗口在屏幕可见区域

#### Q2: 误点了其他程序的按钮？

**解决方案：**
- 提高关闭按钮阈值：`'back_button_threshold': 1.0`
- 使用 `select_region.py` 限制搜索区域
- 增加延迟时间：`'back_button_delay': 1.0`

#### Q3: 程序运行很慢/卡顿？

**解决方案：**
- 增加检测间隔：`'interval': 0.05`
- 关闭不必要的后台程序
- 降低屏幕分辨率

#### Q4: 成功率很低？

**解决方案：**
- 检查 `open_button_timeout` 是否过短
- 调整 `post_click_delay` 延迟时间
- 确保网络连接稳定

## 🛠️ 技术原理

### 图像识别流程

```
屏幕截图 → 转灰度图 → 模板匹配 → 计算相似度 → 判断阈值 → 获取坐标 → 模拟点击
```

### 核心算法

使用 OpenCV 的模板匹配算法：

```python
result = cv2.matchTemplate(screenshot_gray, template, cv2.TM_CCOEFF_NORMED)
```

- **TM_CCOEFF_NORMED**：归一化相关系数匹配法
- 返回值范围：0.0 ~ 1.0（1.0 表示完全匹配）

### 防误触机制

1. **延迟等待**：等待动画完成，界面稳定
2. **区域限制**：只在指定区域搜索
3. **高阈值要求**：100%匹配，杜绝误识别
